# Bloom Care

Landing page responsiva para uma marca fictícia de maquiagem e autocuidado, desenvolvida com foco em apresentação de produtos, identidade visual e experiência de navegação.

Projeto não comercial criado para praticar a construção de uma página de apresentação para uma marca de beleza.

## Demonstração

Acesse a versão online:

[Visualizar Bloom Care](https://projeto-landing-page-jet.vercel.app/)

## Sobre o projeto

A Bloom Care é uma marca fictícia criada para este projeto de Front-End. A landing page apresenta uma proposta visual delicada e feminina, com seções sobre a marca, produtos favoritos, pedidos personalizados e contato.

A interface foi desenvolvida para comunicar uma experiência de beleza e autocuidado, utilizando uma combinação de cores suaves, tipografia editorial, cards de produtos e navegação responsiva.

## Funcionalidades

- Navegação por seções da página;
- Menu responsivo para dispositivos menores;
- Seção principal com apresentação da marca;
- Seção "Sobre nós";
- Catálogo de produtos com nomes e preços;
- Carrossel de produtos com navegação e indicadores;
- Botão para demonstrar interesse em um produto;
- Preenchimento automático do produto escolhido no formulário;
- Rolagem suave até a área de contato;
- Formulário de contato demonstrativo;
- Mensagem de confirmação após o envio do formulário;
- Links para redes sociais;
- Layout responsivo;
- Respeito à preferência do usuário por redução de movimento.

## Como funciona

### Navegação e responsividade

A página possui um menu fixo no topo. Em telas menores, o menu é convertido em um botão expansível utilizando os componentes do Bootstrap.

### Produtos

Os produtos são exibidos em cards dentro de um carrossel. O usuário pode navegar pelos itens e selecionar um produto pelo botão Quero esse.

### Pedido personalizado

Ao selecionar um produto, o nome do item é inserido automaticamente no campo de mensagem do formulário de contato. A página também rola até o formulário para facilitar o preenchimento.

### Formulário de contato

O formulário exibe uma mensagem de confirmação no próprio navegador após o envio. Como o projeto é uma demonstração de Front-End, os dados não são enviados para um servidor real.

## Como executar o projeto localmente

### Pré-requisitos

Você precisa ter um navegador moderno instalado. O projeto não possui dependências locais ou processo de build configurado.

### Instalação

Clone este repositório:

```bash
git clone https://github.com/Marcela-prog/projeto_landing_page.git
```

Entre na pasta do projeto:

```bash
cd projeto_landing_page
```

### Execução

Abra o arquivo index.html no navegador.

Também é possível abrir a pasta no VS Code e utilizar uma extensão como o Live Server durante o desenvolvimento.

Este projeto é uma demonstração de Front-End. O formulário não envia mensagens para um serviço externo e os botões de interesse não realizam compras ou pagamentos.

As fontes, os ícones e parte das imagens são carregados por serviços externos, como Google Fonts, Font Awesome e os assets utilizados no projeto.
